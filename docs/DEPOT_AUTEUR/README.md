## Règles de dépôt

- Le dépôt GitHub doit être **privé** avant d'y placer un document confidentiel de thèse.
- Aucun nom de participant, consentement, correspondance ou donnée de terrain ne doit être
  ajouté au dépôt.
- Le jury simulé examine le **fond scientifique** ; la forme technique du dépôt n'est pas un
  objet de jugement.
- Le terrain n'étant pas encore réalisé, aucun résultat empirique ne doit être présenté comme
  acquis.
